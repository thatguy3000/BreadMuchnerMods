How to play

Game Controls

Keyboard

WASD move

←→ or JL turn

Space shoot or pass

E changes the Blitz intake side

U uses the one-time unstick

Gamepad

Left stick moves

Right stick turns

Right trigger shoots or passes

Left trigger changes the Blitz intake side

D-pad up uses unstick

Offline: choose keyboard or the matching numbered gamepad on each player card. Only one player uses the keyboard at a time. Online: this browser's keyboard or first active gamepad controls its claimed seat.
